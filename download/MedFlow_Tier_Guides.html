Part 1: Starter Tier — Business Process Guide

The Starter tier provides core medical transcription operations for small clinics, solo providers, and individual transcriptionist groups. This guide covers the business workflows, operational procedures, and daily processes for the 12 included sections.

1.2 Daily Operational Workflow

1

Morning (09:00): Check the Overview dashboard for overnight job volume, SLA risk flags, and escalations. Review the Kanban board for jobs in "AI Draft Ready" or "Awaiting QA" status.

2

Mid-morning (10:00): Upload new dictations via the Upload Dictation section. Capture patient ref, provider, facility, priority, and turnaround time. The system auto-creates a job number + calculates the SLA deadline.

3

Afternoon (13:00): Process jobs in My Queue — open the Job Detail Drawer, review the transcript + structured document, make corrections, submit to QA or provider review.

4

Late afternoon (16:00): Review QA findings in the Quality section. Address rework items. Check the Clarifications section for any open queries from providers.

5

End of day (17:00): Check the Analytics dashboard for daily volume + quality trends. Ensure all STAT jobs are delivered. Review the billing usage meter.

1.3 Roles & Responsibilities

1.4 Key Business Rules

  • SLA calculation: Routine = 24h, Urgent = 12h, STAT = 4h (from submission to delivery)
  • QA threshold: Quality score ≥ 70 to pass QA. Below 70 → rework
  • Priority escalation: STAT jobs at 90% SLA → auto-escalate to Operations Manager
  • Clarification SLA pause: When a clarification is open, the SLA timer pauses until resolved
  • Document lock: Once provider e-signs, the document version is immutable

3.2 Linux Installation (Ubuntu/Debian)

1

curl -fsSL https://bun.sh/install | bash source ~/.bashrc
2

Extract the ZIP + navigate:

bun install cp .env.example .env bun run db:push bun run prisma/seed.ts

4.2 AI Agent Workflow (Professional)

The Professional tier includes the full FastAPI backend with 10 AI agents. The pipeline runs semi-autonomously:

1

Intake Validation Agent — validates metadata, checksum, malware scan. Auto-creates job + SLA deadline.

2

Transcription Agent (whisper-large-v3) — speech-to-text with confidence scoring. Flags low-confidence regions.

3

Structuring Agent (glm-4-longcontext) — converts transcript to structured document (SOAP sections, entity extraction).

4

QA Agent — detects medication conflicts, laterality errors, negation issues, hallucination flags.

5

Allocation Agent — routes to best editor (specialty + shift + QA history). Notifies assigned user.

6

SLA / Delivery / Billing / Security / Reporting Agents — monitor throughout the lifecycle.

4.3 Entity Extraction + Hallucination Detection

From the Job Detail Drawer, editors can:

  • Extract Entities — AI auto-suggests SNOMED CT, ICD-10, CPT, RxNorm codes from the transcript. Editor reviews + approves. Never auto-applied.
  • Detect Hallucinations — AI scans for medication conflicts (dose discrepancies), laterality conflicts (left/right), negation conflicts (denies vs reports), numeric inconsistencies. Flags with severity + recommendation.

4.4 Voice Chatbot

The Professional tier includes a floating Voice Chatbot (bottom-right) with:

  • LLM chat — ask questions about the workflow, get AI-powered answers
  • ASR (speech-to-text) — speak into the mic, the chatbot transcribes + responds
  • TTS (text-to-speech) — AI responses are spoken aloud
  • Autonomous agent-run — "Run Transcription Agent" → the chatbot triggers the FastAPI agent + reports the result
  • Quick-action chips — one-click buttons to run specific agents

4.5 Live Dictation

Real-time streaming transcription — provider speaks into the mic, the transcript appears word-by-word with confidence coloring (green ≥0.95, amber 0.80-0.95, red <0.80). Submit as a new job when done.

4.6 Compliance Management

The Continuous Compliance section shows 16 live controls (HIPAA, GDPR, ISO 27001, ISO 13485, HITRUST, SOC 2) with real-time status. The 1-click audit pack generator creates a downloadable evidence bundle. Auto-remediation auto-fixes control failures.

4.7 Daily Operational Workflow (Professional)

In addition to the Starter daily workflow, Professional tier managers should:

  • Morning: Check the AI Ops Copilot for SLA breach predictions + staffing recommendations
  • Weekly: Review the Self-Optimizing Routing panel for auto-adjustments + before/after metrics
  • Monthly: Generate audit packs from Continuous Compliance for internal review
  • Quarterly: Review the Workforce Management leaderboard for productivity + burnout trends
  • As needed: Use the Voice Chatbot to run AI agents + ask operational questions

7.2 Auto-Pilot Workflow

When Auto-Pilot is ON, the entire pipeline runs autonomously:

1

Intake → Transcription → Structuring → QA → Allocation → Delivery — all run without human clicks

2

AI auto-classifies each job: green (auto-approve + deliver), amber (route to editor, skip QA), red (human review)

3

Only ~15% of jobs appear in the Exception Queue for human review

4

Self-Optimizing Routing learns from outcomes weekly — auto-adjusts editor weights

7.3 Autonomous SOC Process

  • AI monitors for: bulk downloads, impossible travel, privilege escalation, brute force, off-hours access
  • Auto-responds: session revoke, IP block, access restrict, MFA challenge, quarantine
  • Response playbooks: 4 pre-configured (bulk download, impossible travel, privilege escalation, brute force)
  • Mean time to respond: 142ms (vs 4 hours for a human SOC)
  • False positive rate: 3.2%

7.4 Enterprise Daily Workflow

  • Morning: Review Auto-Pilot exception queue (only ~15% of jobs need human review). Check Autonomous SOC threat feed.
  • Weekly: Review AI Model Health for drift + retraining status. Check AI Explainability for decision audit trail.
  • Monthly: Generate compliance audit pack. Review Patient Portal DSR requests. Test Voice Ops commands.
  • Quarterly: Complete HIPAA SRA (12-question questionnaire). Review Zero Trust posture + SIEM coverage.
