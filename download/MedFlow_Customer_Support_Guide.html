Question 1: Downloading the Boilerplate

"If I simply download the ZIP file, is it enough, or do I have to go to the directory you specified for boilerplate?"

Q1 Do I just download the ZIP, or go to a specific directory?

Question 2: Running on Windows

"I am using Windows — how can I approach the directory you mentioned?"

Q2 How do I run this on Windows?

The project runs natively on Windows. No Linux or Mac needed. Here's the step-by-step:

Step 1: Download the ZIP

Download medflow-transcribe-ai-boilerplate.zip from the download panel to your Windows machine (typically the Downloads folder).

Step 2: Extract the ZIP

1

Right-click the ZIP file → "Extract All..."

Choose a destination folder, e.g., C:\Projects\medflow

Click "Extract"

Step 4: Run the App (PowerShell)

1

Open PowerShell → navigate to the project:

cd C:\Projects\medflow
2

bun install

(or: npm install)

3

Q3 Will it run on Windows?

Yes — it runs natively on Windows. Every component is cross-platform:

ComponentWindows Compatible?How It Works

Prisma + SQLiteYesSQLite is file-based (no server) — works on Windows out of the box
FastAPI backendYesPython 3.12 runs natively on Windows
Tailwind CSS + shadcn/uiYesBuilt into Next.js build process — no separate install
Docker ComposeOptionalUse Docker Desktop for Windows (only for Postgres/Redis/MinIO — not required for basic use)
Caddy gatewayOptionalOnly needed for the XTransformPort proxy. The app works WITHOUT it (uses Next.js proxy + static fallback)
z-ai-web-dev-sdk (AI)YesServer-side only — runs inside Next.js API routes on Windows
If Anything Doesn't Work — Use WSL2
If you hit any Windows-specific issue (rare), use WSL2 (Windows Subsystem for Linux):

Step 1: Open PowerShell as Administrator → run wsl --install
Step 2: Restart your PC
Step 3: Open "Ubuntu" from the Start menu
Step 4: Install Bun + Python inside WSL2:
  curl -fsSL https://bun.sh/install | bash
  sudo apt update && sudo apt install python3 python3-pip
Step 5: Navigate to your project (accessible at /mnt/c/Projects/medflow)
Step 6: Run the same commands as Linux

WSL2 gives 100% Linux compatibility — everything works identically to the development sandbox.

Support Playbook — Handling Customer Questions

Here are the most common questions buyers will ask + how to answer them:

Common Support Questions + Answers

FAQ "I get an error running 'bun install' — what do I do?"

Answer: "Make sure you have Bun installed. Open PowerShell and run irm bun.sh/install.ps1 | iex. If Bun doesn't work, install Node.js 20+ from nodejs.org and use npm install instead of bun install. All other commands work the same — just replace 'bun' with 'npx' or 'npm run'."

FAQ "The app shows 'Failed to load' on AI Agents / Integrations"

Answer: "Those sections need the Python FastAPI backend running. Open a second terminal: cd mini-services/ai-agents-service → pip install -r requirements.txt → python -m uvicorn main:app --port 8000 --reload. If you don't want to run Python, the sections still show pre-baked demo data (3-tier static fallback) — the app works without the backend."

FAQ "How do I connect real AI (OpenAI/Whisper)?"

Answer: "Set OPENAI_API_KEY in your .env file. The Voice Chatbot + Live Dictation already use the z-ai-web-dev-sdk (pre-installed, no key needed). For the 10 AI agents, edit mini-services/ai-agents-service/main.py to call real AI APIs instead of the simulated responses."

FAQ "How do I connect real Stripe billing?"

Answer: "Set STRIPE_SECRET_KEY + STRIPE_PUBLISHABLE_KEY in .env. Then edit src/app/api/medflow/stripe/route.ts to replace the mock data with real Stripe API calls. See docs/CUSTOMIZATION.md section 6 for code examples."

FAQ "Is this HIPAA-compliant?"

Answer: "The platform implements HIPAA-aligned technical safeguards (encryption, RBAC, audit logging, MFA). It is NOT certified — you must complete your own Security Risk Analysis (the built-in HIPAA SRA tool helps with this) + sign BAAs with your cloud providers. The 34-page compliance spec PDF maps every control to its regulatory citation."

FAQ "Can I use this for real patients?"

Answer: "Yes — but you must: (1) complete HIPAA compliance certification, (2) sign a BAA with your cloud provider (AWS/Azure/GCP), (3) connect real AI providers, (4) configure data retention + encryption policies. The compliance spec PDF + HIPAA SRA tool guide you through this."

FAQ "How do I change the colors / logo / name?"

Answer: "See docs/CUSTOMIZATION.md — change colors in src/app/globals.css, replace the logo in public/medflow-logo.png, update the app name in src/lib/medflow/constants.ts. The theme is teal/green (#0B5345 + #1ABC9C) — change the CSS variables to your brand colors."
